A project focused on evaluating tax calculations against a consistent set of test cases.

## The goal

Make it easier to compare results, identify discrepancies, and understand where a calculation needs closer review.

## The approach

Define test cases with explicit inputs, assumptions, and expected results. Record the tax year and jurisdiction for each case so comparisons stay meaningful.

Compare calculated results with the expected values and summarize differences in a clear, repeatable report.
